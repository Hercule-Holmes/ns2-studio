# Session 工单目录

每个 `Sxx-*.md` 是可交给 **独立 AI/人工 Session** 的执行说明。

## 使用方法

1. 看 [../architecture/04-SESSION-MATRIX.md](../architecture/04-SESSION-MATRIX.md) 选任务  
2. 打开对应工单，把「上下文注入」列表读完  
3. 只改 **Owns** 目录  
4. 完成后改 Status，更新 MATRIX
